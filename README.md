# ЭЛЛАДА — газета древнего мира

Интерактивный лонгрид о Древней Греции, свёрстанный как винтажная газета. Обложка разворачивается в полноценный номер: Афины и демократия, наука, философия, театр, Олимпийские игры, хронология, карта, быт и наследие.

**Живая версия:** https://samprav67-bit.github.io/hellas-daily/

## Что внутри

- **Обложка-сюрприз.** Газета сложена, перевязана сургучной печатью и разворачивается в 3D при клике.
- **Настоящая вёрстка.** Крупный заголовок, буквица, колонки, линейки, подписи и «страницы» — как в печатном издании.
- **Оракул.** Плавающая монета с совой открывает свиток с дельфийскими изречениями; можно листать максимы.
- **Хроника.** Горизонтальная лента с датами и кнопками прокрутки.
- **Карта и быт.** Древняя Греция на карте, распорядок дня афинянина, меню симпосия и слова греческого происхождения.
- **Доступность.** Клавиатурная навигация, ловушка фокуса в модальном окне, `aria-current`, поддержка `prefers-reduced-motion`, ссылка для пропуска обложки.
- **Без зависимостей.** Чистые HTML, CSS и JavaScript. Шрифты и изображения хранятся локально.

## Разделы

1. Главное — Афины и рождение демократии.
2. Наука — от Фалеса до Антикитерского механизма.
3. Философия — Сократ, Платон, Аристотель и школы.
4. Театр и Олимпийские игры.
5. Хроника — ключевые даты.
6. Карта Древней Греции.
7. Быт — дом, еда, распорядок дня, симпосий.
8. Наследие — что Греция оставила современному миру.

## Локальный запуск

```bash
cd hellas-daily
python -m http.server 8000
```

Откройте http://127.0.0.1:8000/.
